# Amazon Best Selling Books Web Scraping

A Python web scraping project that collects Amazon India's best-selling books and performs basic data analysis.

## Tools Used

- Python
- Requests
- BeautifulSoup
- Pandas
- Matplotlib
- Jupyter Notebook

## Data Collected

- Book Name
- Author
- Rating
- Customers Rated
- Price

## Analysis

- Top 10 highest-priced books
- Top-rated books
- Most customer-rated books
- Rating vs. Customers Rated

## Files

- `web_scraping.ipynb` — Web scraping and analysis notebook
- `amazon_products.csv` — Scraped book data

## How to Run

```bash
pip install requests beautifulsoup4 pandas matplotlib
